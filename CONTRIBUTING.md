# Contributing to AgentJ

Thanks for helping make Java agent development simpler.

## Local setup

- JDK 21+
- Maven 3.9+

```bash
mvn test
```

## Pull requests

Keep public APIs small. Prefer plain Java types. Add a test for behavior changes and update the README when introducing a user-visible feature.

## Issues

Please include the Java version, AgentJ version, model/provider, and a minimal reproduction where possible.
